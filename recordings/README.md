# Shared recordings

Audio files in this folder appear on the site for everyone, as narrator choices for the matching story and language.

Upload the file exactly as the site's **Save file** button names it:

```
<story-id>.<language>.<narrator>.<extension>
sleepy-moon.ko.엄마.m4a
little-bear.en.Dad.webm
```

- Story ids: `sleepy-moon`, `little-bear`, `little-star`, `bunny-walk`, `little-cloud`
- Languages: `en`, `ko`, `zh`

This repository is public, so anyone with the link can hear these recordings.
To remove a recording, delete its file here.
